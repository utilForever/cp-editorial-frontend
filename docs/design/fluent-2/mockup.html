CP Editorial / Fluent 2

Design proposal, prepared before implementation. A quiet archive with search as the first action.

Tokens and key states

Use existing CSS and native controls. No component dependency: current interactions need styling, labeling and focus management, rather than replacement.

Role Light / dark Rule
Canvas / surface #f5f5f5 / #fafafa → #141414 / #1f1f1f Neutral backgrounds; white/raised surface for content.
Text / secondary #242424 / #616161 → #f5f5f5 / #c7c7c7 4.5:1 minimum, including metadata.
Brand #0f6cbd → #479ef5 Primary action and selected navigation; selection also has an underline.
Controls #707070 → #999999 borders 44px minimum targets; 4px corners; darker hover/pressed, 2px focus outline.
Layout 4 / 8 / 12 / 16 / 24 / 32 / 48px Related labels stay with controls; grids collapse; titles wrap in full.
Typography 14 / 16 / 20 / 28 / 40px System fonts with Korean/Japanese fallbacks; rem sizes and unitless leading.
Feedback Neutral status; red error panel Text + status/alert announcement; recovery link or Retry. Disabled controls use native disabled.

Reference: Microsoft Fluent 2. Mobile navigation expands in document flow; Escape returns focus to Menu. A skip link leads to the main region.
